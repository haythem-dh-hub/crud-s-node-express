# Node.js & Express CRUD Application

Full-stack CRUD (Create, Read, Update, Delete) web application built using Node.js, Express.js, and modern frontend technologies.

The project demonstrates backend API development, database integration, dynamic frontend interaction, and complete data management workflows between client and server.

## Features

- Create new records
- Read and display data
- Update existing records
- Delete records
- RESTful API architecture
- Frontend and backend integration
- Dynamic user interface
- Database connectivity
- Error handling and validation

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB / MySQL
